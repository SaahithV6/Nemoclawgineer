# OpenClaw Engineering executor

This repo is the **Brev CAE executor** for **OpenClaw** (not a standalone "nemoclaw" app).

- **OpenClaw agent** infers JobSpec for any demo via `skills/openclaw-engineering/SKILL.md`
- **MCP:** `openclaw_engineering_submit_job`, `openclaw_engineering_job_status`, …
- **Package:** `openclaw_engineering`
- **Discord/Gmail:** OpenClaw channels only

Implement changes in `openclaw_engineering/` and keep the skill as the contract.
